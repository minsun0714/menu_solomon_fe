# 메뉴솔로몬 요구사항 명세

- 사용자 식별
  - 별도의 로그인 기능 없음
  - 사용자 식별이 필요한 최초 요청에서 익명 사용자 생성
  - 익명 사용자 식별 토큰을 `HttpOnly` 쿠키로 발급
  - 같은 브라우저에서는 같은 사용자로 식별
  - 한 사용자가 여러 팀에 가입 가능
  - 쿠키를 삭제하거나 다른 브라우저로 접속하면 새로운 사용자로 인식
  - 닉네임은 서버에서 구분 가능한 값으로 자동 생성
  - 프로필 사진은 사용하지 않음
  - 공개 초대 미리보기 조회만으로는 익명 사용자나 세션을 생성하지 않음

- 비회원 또는 비팀원
  - 랜딩 페이지
    - 서비스 이름
    - 서비스 소개
    - 익명 세션이 있는 사용자의 참여 중인 팀 목록
    - 팀 생성
  - 팀 초대 링크 진입
    - 초대 코드를 직접 입력하는 기능 없음
    - 완성된 초대 링크로만 진입
  - 초대받은 팀 미리보기
    - 팀 이름
    - 팀 소개
    - 팀원 수
    - 팀원 목록
    - 이미 가입한 팀인지 표시
    - 미가입 사용자에게 팀 참여 버튼 제공
  - 실제 팀 페이지 접근 제한
    - 팀 미가입자는 팀 상세 페이지에 접근할 수 없음
    - 초대 토큰 없이 팀 URL로 직접 접근하면 팀 데이터를 노출하지 않음
    - 초대 링크로 참여하라는 안내 표시

- 팀
  - 관리자만
    - 팀 정보 수정
      - 팀 이름 수정
      - 팀 소개 수정
    - 팀 관리자 변경
      - 최초 관리자는 팀 생성자
      - 다른 팀원에게 관리자 권한 위임
    - 팀 삭제
    - 초대 링크 재발급
      - 재발급 즉시 기존 링크 무효화
  - 모든 익명 사용자
    - 팀 생성
      - 팀 이름 필수
      - 팀 소개 선택
      - 생성자는 자동으로 관리자 지정
      - 팀 생성 직후 해당 팀 페이지로 이동
    - 팀 가입
      - 초대 링크 공유 방식만 사용
      - 가입 요청 시 익명 세션이 없으면 세션 생성 후 가입
      - 동일 사용자의 중복 가입 방지
    - 내 소속 팀 목록 조회
      - 페이지네이션 없이 전체 조회
      - 정렬은 서버에서 처리
        - 최근 확정 점심 순
        - 팀 이름 순
        - 멤버 많은 순
  - 팀원만
    - 팀 상세 정보 조회
      - 현재 사용자의 팀 역할 포함
    - 팀원 목록 조회
    - 초대 링크 조회 및 공유
    - 팀 탈퇴
      - 일반 멤버는 즉시 탈퇴
      - 관리자가 다른 멤버와 함께 있는 경우
        - 다른 멤버에게 관리자 권한을 위임한 후 탈퇴
        - 권한 위임과 탈퇴는 하나의 작업으로 처리
      - 관리자 혼자 남은 경우
        - 권한 위임 없이 탈퇴 가능
        - 탈퇴 즉시 팀과 관련 데이터 삭제

- 사무실 위치
  - 팀원만 조회 가능
  - 모든 팀원이 등록 및 변경 가능
  - 카카오 장소 검색으로 주소 선택
  - 팀 공용 데이터로 서버에 저장
  - 지도에 사무실 위치 표시

- 맛집
  - 팀원만 목록 및 상세 조회 가능
  - 맛집 검색
    - 백엔드가 카카오 장소 검색 API를 프록시
    - 검색 결과 페이지네이션
    - 카카오 REST API 키를 프론트에 노출하지 않음
  - 팀 맛집 등록
    - 모든 팀원이 등록 가능
    - 카카오 장소 검색 결과로 등록
    - 같은 팀에 같은 식당 중복 등록 불가
  - 팀 맛집 목록 조회
    - 식당 이름, 메뉴 또는 카테고리, 지역으로 검색
    - 카테고리별 필터
      - 카테고리별 식당 개수 표시
    - 정렬은 서버에서 처리
      - 별점 높은 순
      - 최근 등록 순
      - 이름 순
    - 전체 식당 수 표시
    - 전체 팀 리뷰 수 표시
    - 각 식당의 최근 리뷰 한 건 표시
    - 최근 리뷰 클릭 시 전체 리뷰 모달 표시
    - 지도에 등록된 식당 위치와 이름 표시
  - 팀 맛집 상세 조회
    - 식당 정보
    - 평균 별점
    - 리뷰 목록
  - 팀 맛집 삭제
    - 모든 팀원이 삭제 가능
    - 삭제 메뉴는 식당 카드의 더보기 메뉴에 표시
    - 팀 식당 연결과 해당 팀 리뷰 삭제
    - 다른 팀에서 사용하는 식당 원본은 삭제하지 않음

- 맛집별 별점 및 리뷰
  - 팀원만 조회 및 저장 가능
  - 리뷰 목록 조회
    - 최신순
    - 작성자 닉네임
    - 별점
    - 내용
  - 내 리뷰 저장
    - 별점 1~5
    - 리뷰 내용 필수
    - 리뷰 내용 최대 200자
    - 1인 1팀 식당 1리뷰
    - 기존 내 리뷰가 없으면 생성
    - 기존 내 리뷰가 있으면 같은 리뷰의 별점과 내용을 덮어쓰기
    - 별도의 리뷰 수정 API 없음
    - 다른 팀원의 리뷰는 변경할 수 없음
  - 내 리뷰 삭제
  - 식당 평균 별점 조회

- 오늘의 점심 메뉴 정하기
  - 팀원만 조회 및 참여 가능
  - 멤버
    - 오늘의 팀원별 참여 여부 목록
    - 모든 팀원이 본인 및 다른 팀원의 참여 여부 변경 가능
    - 참여와 불참 상태를 서로 다른 색상의 뱃지로 표시
    - 불참 처리된 팀원의 기존 투표 내역 삭제
  - 오늘의 투표
    - 생성
      - 한 팀에서 투표를 2개 이상 생성 가능
      - 투표 이름
      - 종료 시간
        - 기본값은 생성 직후 3시간
    - 수정
      - 모든 팀원이 진행 중인 투표 이름 수정 가능
      - 모든 팀원이 진행 중인 투표 종료 시간 수정 가능
    - 투표 다시 시작
      - 확정 전 투표에서 실행 가능
      - 기존 후보군 유지
      - 기존 투표 내역 전체 삭제
      - 종료 시간을 실행 시점부터 3시간 뒤로 변경
      - 확인 모달 표시
    - 조회
    - 삭제
      - 모든 팀원이 삭제 가능
      - 투표 카드 우측 상단 더보기 메뉴에 표시
  - 후보
    - 모든 팀원이 후보 추가 및 삭제 가능
    - 카카오 장소 검색으로 식당을 후보에 추가
    - 등록된 팀 맛집을 후보에 추가
    - 오늘의 추천 점심 조회
      - 사용자가 버튼을 눌렀을 때만 표시
      - 추천 식당은 한 번에 한 곳만 표시
      - 새로고침 버튼으로 다른 추천 조회
      - 추천 식당을 후보로 추가하면 추천 영역 닫기
      - 추천 알고리즘
        - 불참 팀원의 리뷰를 제외한 팀 식당 별점 반영
        - 최근 7일 이내 확정 메뉴로 선택된 식당 제외
    - 후보 목록 조회
    - 후보 삭제 시 해당 후보에 등록된 투표 내역도 삭제
  - 투표
    - 복수 선택 가능
      - 한 사람이 선택할 수 있는 후보 수 제한 없음
      - 같은 후보에는 한 번만 투표 가능
    - 투표 저장
      - 선택한 후보 목록 전체를 한 번에 저장
    - 투표 변경
      - 기존 선택 목록을 새로운 선택 목록으로 덮어쓰기
    - 투표 취소
      - 본인의 선택 내역 전체 삭제
    - 투표 목록 및 결과 조회
      - 후보별 득표수 표시
      - 득표율은 투표에 참여한 사람 수를 기준으로 계산
      - 복수 투표이므로 후보별 득표율 합계는 100%를 초과할 수 있음
  - 최다 득표 메뉴
    - 최다 득표 후보 조회
    - 공동 최다 득표 여부 조회
  - 확정 메뉴
    - 자동 확정
      - 지정된 종료 시간이 지나면 처리
      - 최다 득표 후보가 한 곳이면 자동 확정
      - 최다 득표 후보가 여러 곳이면 자동 확정하지 않음
    - 수동 확정
      - 동점인 경우 수동 확정 가능
      - 투표 생성자만 가능
    - 확정 메뉴 수정
      - 투표 생성자만 가능
    - 확정 메뉴 삭제
      - 투표 생성자만 가능

- 확정 메뉴 히스토리
  - 팀원만 조회 가능
  - 확정된 점심을 상단에 우선 표시
  - 주간 조회
    - 월요일 시작 기준
    - 주 단위 달력에 표시
  - 월간 조회
    - 월 단위 달력에 표시
  - 날짜 계산은 한국 시간 기준
